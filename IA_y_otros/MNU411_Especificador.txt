Reglas Transversales de Estabilidad Numérica (Nieves & Domínguez, Cap. 1):
1. Comparaciones seguras en punto flotante (Ej. 1.5): Nunca evaluar igualdad
   exacta (X == Y) para detener ciclos; usar tolerancia: |X - Y| <= EPS.
2. Doble criterio de parada en búsqueda de raíces (Algoritmos 2.2 - 2.4):
   - Criterio de convergencia entre iteraciones: |x_{i+1} - x_i| <= EPS
   - Criterio de exactitud funcional: |f(x)| <= EPS1
   - Control de divergencia: Límite MAXIT con mensaje explícito de falla.
3. Prevención de errores graves (Sección 1.3): Validar denominadores cercanos
   a cero (|denom| < 1e-15) para evitar Overflow y advertir pérdida de cifras
   significativas por resta de números casi iguales.

MÓDULO 1: ANÁLISIS DE ERRORES (engine/errores.py - Cap. 1)
- Error Absoluto (Sección 1.3): EA = |p* - p|
- Error Relativo (Sección 1.3): ER = |p* - p| / |p|, con p != 0
- Error Porcentual (Sección 1.3): ERP = ER * 100
- Cota Teórica de Redondeo: (1/2) * 10^-d
- Error de Truncamiento con Serie de Taylor (Polinomio P_n(x))
- Propagación de Error Multivariable (Sección 1.3e): E_f ≈ Suma(|∂f/∂x_i| * E_{x_i})

MÓDULO 2: ECUACIONES NO LINEALES (engine/no_lineales.py - Cap. 2)

PIEZA 2.1: Método de Punto Fijo (Sección 2.1, Algoritmo 2.1)
- Transformación: f(x) = 0  -->  x = g(x)
- Verificación teórica de convergencia (Ec. 2.10): Evaluar |g'(x0)| < 1 como
  indicador suficiente de convergencia (monotónica si 0 < g'(x) < 1;
  oscilatoria si -1 < g'(x) < 0).
- Iteración: x_{i+1} = g(x_i)
- Parada: |x_{i+1} - x_i| <= EPS o I >= MAXIT.

PIEZA 2.2: Método de Bisección (Sección 2.5, Ec. 2.15)
- Condición inicial (Teorema de Bolzano): f(x_I) * f(x_D) < 0 en [x_I, x_D].
- Estimación teórica de iteraciones (Ec. 2.15):
  n = ceil((ln(|x_D - x_I|) - ln(EPS)) / ln(2))
- Punto medio: x_M = (x_I + x_D) / 2
- Actualización: Si f(x_I) * f(x_M) < 0 -> x_D = x_M; en caso contrario x_I = x_M.
- Parada: |x_M_nuevo - x_M_anterior| <= EPS o |f(x_M)| <= EPS1.

PIEZA 2.3: Método de Posición Falsa / Regula-Falsi (Sección 2.4, Algoritmo 2.4)
- Condición inicial: f(x_I) * f(x_D) < 0.
- Fórmula (Ec. 2.14):
  x_M = x_D - [(x_D - x_I) * f(x_D)] / [f(x_D) - f(x_I)]
- Actualización: Si f(x_D) * f(x_M) > 0 -> x_D = x_M; si < 0 -> x_I = x_M.
- Parada: |f(x_M)| <= EPS1 o |x_D - x_I| <= EPS.

PIEZA 2.4: Método de la Secante (Sección 2.3, Algoritmo 2.3)
- Requiere dos puntos iniciales x0, x1 (no requiere cambio de signo).
- Fórmula (Ec. 2.13):
  x_{i+1} = x_i - [(x_i - x_{i-1}) * f(x_i)] / [f(x_i) - f(x_{i-1})]
- Parada: |x_{i+1} - x_i| <= EPS o |f(x_{i+1})| <= EPS1.

PIEZA 2.5: Método de Newton-Raphson (Sección 2.2, Algoritmo 2.2 + Extensión)
- 1er Orden (Ec. 2.12): x_{i+1} = x_i - f(x_i) / f'(x_i)
- 2do Orden (Aceleración con segunda derivada):
  x_{i+1} = x_i - [f(x_i) * f'(x_i)] / [(f'(x_i))^2 - f(x_i) * f''(x_i)]
- Parada: |x_{i+1} - x_i| <= EPS o |f(x_{i+1})| <= EPS1.

import numpy as np

class ErroresEngine:
    @staticmethod
    def error_absoluto(x: float, x_bar: float) -> float:
        """Calcula el Error Absoluto: |x - x̄|"""
        return abs(x - x_bar)

    @staticmethod
    def error_relativo(x: float, x_bar: float) -> float:
        """Calcula el Error Relativo: |x - x̄| / |x|"""
        if x == 0:
            raise ValueError("El valor real (x) no puede ser cero para el error relativo.")
        return abs(x - x_bar) / abs(x)

    @staticmethod
    def error_porcentual(x: float, x_bar: float) -> float:
        """Calcula el Error Porcentual: Error Relativo * 100"""
        return ErroresEngine.error_relativo(x, x_bar) * 100.0

    @staticmethod
    def cota_redondeo(d: int) -> float:
        """Calcula la Cota Máxima Teórica de Redondeo: (1/2) * 10^-d"""
        if d < 1:
            raise ValueError("Las cifras significativas (d) deben ser al menos 1.")
        return 0.5 * (10.0 ** -d)

    @staticmethod
    def error_truncamiento_taylor(func_str: str, x0: float, x_eval: float, orden: int):
        """
        Calcula el Polinomio de Taylor y el Error de Truncamiento para f(x).
        Retorna: (polinomio_latex, val_real, val_aprox, error_truncamiento, cota_teorica)
        """
        x_sym = sp.Symbol('x')
        expr = sp.sympify(func_str)
        
        # 1. Valor Real
        val_real = float(expr.subs(x_sym, x_eval))
        
        # 2. Polinomio de Taylor de orden 'd'
        taylor_poly = expr.series(x_sym, x0, n=orden + 1).removeO()
        val_aprox = float(taylor_poly.subs(x_sym, x_eval))
        
        # 3. Error y Cota Teórica
        e_t = abs(val_real - val_aprox)
        cota_teorica = 1.0 * (10.0 ** -orden)
        
        return {
            "polinomio_sympy": taylor_poly,
            "polinomio_latex": sp.latex(taylor_poly),
            "val_real": val_real,
            "val_aprox": val_aprox,
            "error_truncamiento": e_t,
            "cota_teorica": cota_teorica,
            "cumple_cota": e_t <= cota_teorica
        }

    @staticmethod
    def propagacion_error(func_str: str, valores_dict: dict, errores_dict: dict):
        """
        Calcula la propagación de error en funciones multivariable mediante Derivadas Parciales.
        Formula: E_A(total) = Suma( |∂f/∂xi| * E_A(xi) )
        """
        expr = sp.sympify(func_str)
        variables = sorted(list(expr.free_symbols), key=lambda s: s.name)
        
        # Mapeo de variables
        val_pares = [(v, valores_dict[v.name]) for v in variables]
        
        # Valor nominal de la función original
        y_0 = float(expr.subs(val_pares))
        
        e_a_total = 0.0
        detalles_derivadas = []
        
        for v in variables:
            df_var = sp.diff(expr, v)
            df_val = float(df_var.subs(val_pares))
            err_var = errores_dict[v.name]
            
            aporte = abs(df_val) * err_var
            e_a_total += aporte
            
            detalles_derivadas.append({
                "variable": v.name,
                "derivada_sympy": df_var,
                "derivada_latex": sp.latex(df_var),
                "valor_evaluado": df_val,
                "error_variable": err_var,
                "aporte_error": aporte
            })
            
        return {
            "valor_nominal": y_0,
            "error_total": e_a_total,
            "detalles": detalles_derivadas,
            "resultado_intervalo": f"{y_0} ± {e_a_total}"
        }]]></archivo>

import numpy as np


class InterpolacionEngine:

    # -------------------------------------------------------------------------
    # VALIDACIONES INTERNAS
    # -------------------------------------------------------------------------
    @staticmethod
    def _parsear_escalar(valor, nombre_parametro):
        try:
            val = float(valor)
        except (TypeError, ValueError):
            raise ValueError(
                f"Entrada inválida en '{nombre_parametro}': se recibió '{valor}', "
                "pero debe ser un número real (no se permiten letras ni texto)."
            )
        if math.isnan(val) or math.isinf(val):
            raise ValueError(f"El parámetro '{nombre_parametro}' no puede ser NaN ni infinito.")
        return val

    @staticmethod
    def _validar_datos_base(x_vals, y_vals):
        if len(x_vals) != len(y_vals):
            raise ValueError("Las columnas x y f(x) deben tener la misma cantidad de filas.")
        if len(x_vals) < 2:
            raise ValueError("Se requieren al menos 2 puntos tabulados para interpolar.")

        x_limpio, y_limpio = [], []
        for idx, (xv, yv) in enumerate(zip(x_vals, y_vals), start=1):
            try:
                x_num = float(xv)
            except (TypeError, ValueError):
                raise ValueError(
                    f"Dato inválido en columna 'x', fila {idx}: '{xv}' no es un número válido."
                )
            try:
                y_num = float(yv)
            except (TypeError, ValueError):
                raise ValueError(
                    f"Dato inválido en columna 'f(x)', fila {idx}: '{yv}' no es un número válido."
                )
            x_limpio.append(x_num)
            y_limpio.append(y_num)

        x = np.array(x_limpio, dtype=float)
        y = np.array(y_limpio, dtype=float)

        if np.any(np.isnan(x)) or np.any(np.isnan(y)) or np.any(np.isinf(x)) or np.any(np.isinf(y)):
            raise ValueError("La tabla contiene celdas vacías (NaN) o valores infinitos.")
        if len(np.unique(x)) != len(x):
            raise ValueError("Los valores de 'x' no pueden repetirse.")

        return x, y
    @staticmethod
    def _validar_paso_constante(x, xp):
        diferencias = np.diff(x)
        h = float(diferencias[0])

        if h <= 0 or not np.all(diferencias > 0):
            raise ValueError("Para Newton, los valores de x deben estar ordenados de forma estrictamente creciente.")
        if not np.allclose(diferencias, h, rtol=1e-7, atol=1e-9):
            raise ValueError("Los datos no tienen separación constante h; use el método de Lagrange.")
        if xp < x[0] or xp > x[-1]:
            raise ValueError(
                f"El valor buscado ({xp}) está fuera del rango [{x[0]}, {x[-1]}]. "
                "Newton solo aplica para interpolación; use Lagrange para extrapolar."
            )

        return h

    # -------------------------------------------------------------------------
    # 5.1.A NEWTON HACIA ADELANTE (TRIANGULAR SUPERIOR)
    # -------------------------------------------------------------------------
    @staticmethod
    def newton_adelante(x_vals, y_vals, xp):
        x, y = InterpolacionEngine._validar_datos_base(x_vals, y_vals)
        xp = float(xp)
        h = InterpolacionEngine._validar_paso_constante(x, xp)
        n = len(x)

        # Matriz de diferencias finitas alineada hacia arriba (triangular superior)
        diff = np.full((n, n), np.nan)
        diff[:, 0] = y
        for k in range(1, n):
            for i in range(n - k):
                diff[i, k] = diff[i + 1, k - 1] - diff[i, k - 1]

        x0 = float(x[0])
        P = (xp - x0) / h

        resultado = float(diff[0, 0])
        terminos = [
            {
                "orden": 0,
                "diferencia": round(float(diff[0, 0]), 6),
                "factor_P": 1.0,
                "aporte": round(resultado, 6),
            }
        ]

        prod_p = 1.0
        for k in range(1, n):
            prod_p *= (P - (k - 1))
            coef_p = prod_p / math.factorial(k)
            delta_y = float(diff[0, k])
            aporte = coef_p * delta_y
            resultado += aporte
            terminos.append(
                {
                    "orden": k,
                    "diferencia": round(delta_y, 6),
                    "factor_P": round(coef_p, 6),
                    "aporte": round(aporte, 6),
                }
            )

        # Construcción de tabla tabular para UI y reporte PDF
        tabla_diferencias = []
        for i in range(n):
            fila = {"i": i, "x_i": round(float(x[i]), 6), "f(x_i)": round(float(diff[i, 0]), 6)}
            for k in range(1, n):
                col_name = f"Δ^{k}f"
                fila[col_name] = None if np.isnan(diff[i, k]) else round(float(diff[i, k]), 6)
            tabla_diferencias.append(fila)

        return {
            "metodo": "Interpolación de Newton hacia Adelante",
            "solucion": round(resultado, 6),
            "xp": xp,
            "x0": x0,
            "h": round(h, 6),
            "P": round(P, 6),
            "terminos": terminos,
            "iteraciones": tabla_diferencias,
        }

    # -------------------------------------------------------------------------
    # 5.1.B NEWTON HACIA ATRÁS (TRIANGULAR INFERIOR)
    # -------------------------------------------------------------------------
    @staticmethod
    def newton_atras(x_vals, y_vals, xp):
        x, y = InterpolacionEngine._validar_datos_base(x_vals, y_vals)
        xp = float(xp)
        h = InterpolacionEngine._validar_paso_constante(x, xp)
        n = len(x)

        # Matriz de diferencias finitas alineada hacia abajo (triangular inferior)
        diff = np.full((n, n), np.nan)
        diff[:, 0] = y
        for k in range(1, n):
            for i in range(k, n):
                diff[i, k] = diff[i, k - 1] - diff[i - 1, k - 1]

        x0 = float(x[-1])
        P = (xp - x0) / h

import numpy as np
import sympy as sp


def _validar_puntos_interpolacion(x_vals, y_vals, min_puntos: int = 2):
    """
    Valida consistencia dimensional y unicidad de abscisas (Regla 3 de estabilidad:
    evitar división entre cero por nodos repetidos).
    """
    x = np.asarray(x_vals, dtype=float)
    y = np.asarray(y_vals, dtype=float)

    if x.ndim != 1 or y.ndim != 1 or len(x) != len(y):
        return False, "Los vectores X e Y deben ser unidimensionales y tener la misma longitud.", None, None

    if len(x) < min_puntos:
        return False, f"Se requieren al menos {min_puntos} puntos para este método.", None, None

    if np.any(np.isnan(x)) or np.any(np.isnan(y)) or np.any(np.isinf(x)) or np.any(np.isinf(y)):
        return False, "Los datos contienen valores NaN o infinitos.", None, None

    # Verificar nodos X duplicados (|x_i - x_j| < 1e-15)
    n = len(x)
    for i in range(n):
        for j in range(i + 1, n):
            if abs(x[i] - x[j]) < 1e-15:
                return (
                    False,
                    f"Error de estabilidad (División por cero): existen abscisas repetidas (x[{i}] = x[{j}] = {x[i]}).",
                    None,
                    None,
                )

    return True, "OK", x, y

# PIEZA 5.4.C: DIFERENCIAS DIVIDIDAS DE NEWTON (Nieves & Domínguez, Sec. 5.3-5.4)

def interpolacion_diferencias_divididas(x_vals, y_vals, x_eval: float) -> dict:
    """
    Calcula el polinomio interpolante de Newton mediante tabla de diferencias divididas
    (Algoritmos 5.3 y 5.4 de Nieves & Domínguez) y lo evalúa en x_eval usando
    esquema anidado de Horner (Sec. 2.10) para minimizar errores de redondeo.
    Soporta paso variable o constante, interpolación y extrapolación.
    """
    valido, msg, x, y = _validar_puntos_interpolacion(x_vals, y_vals, min_puntos=2)
    if not valido:
        return {"exito": False, "mensaje": msg}

    n = len(x)
    # Matriz n x n para la tabla de diferencias divididas
    tabla = np.zeros((n, n), dtype=float)
    tabla[:, 0] = y

    pasos = []
    # Construcción iterativa de diferencias divididas de orden j = 1 .. n-1
    for j in range(1, n):
        for i in range(n - j):
            denom = x[i + j] - x[i]
            if abs(denom) < 1e-15:
                return {
                    "exito": False,
                    "mensaje": f"Denominador cercano a cero en orden {j}: x[{i + j}] - x[{i}] = {denom}.",
                }
            num = tabla[i + 1, j - 1] - tabla[i, j - 1]
            tabla[i, j] = num / denom
            pasos.append(
                {
                    "orden": j,
                    "fila": i,
                    "formula": f"f[x_{i}..x_{i+j}] = ({tabla[i+1, j-1]:.6g} - {tabla[i, j-1]:.6g}) / ({x[i+j]:.6g} - {x[i]:.6g})",
                    "valor": float(tabla[i, j]),
                }
            )

    # Coeficientes b_j = f[x_0, x_1, ..., x_j] (diagonal superior)
    coeficientes = [float(tabla[0, j]) for j in range(n)]

    # Evaluación numérica anidada (Horner generalizado para base de Newton)
    resultado = coeficientes[-1]
    for k in range(n - 2, -1, -1):
        resultado = resultado * (x_eval - x[k]) + coeficientes[k]

    # Construcción simbólica con SymPy (forma Newton y forma canónica expandida)
    x_sym = sp.Symbol("x")
    poli_newton_expr = sp.Float(coeficientes[0], 10)
    termino_prod = sp.Integer(1)
    for j in range(1, n):
        termino_prod = termino_prod * (x_sym - sp.Float(x[j - 1], 10))
        poli_newton_expr += sp.Float(coeficientes[j], 10) * termino_prod

    poli_expandido_expr = sp.expand(poli_newton_expr)

    # Detección de interpolación vs extrapolación
    x_min, x_max = float(np.min(x)), float(np.max(x))
    es_extrapolacion = bool(x_eval < x_min or x_eval > x_max)

    return {
        "exito": True,
        "mensaje": "Cálculo completado exitosamente.",
        "metodo": "Diferencias Divididas de Newton (Pieza 5.4.C)",
        "x": x.tolist(),
        "y": y.tolist(),
        "x_eval": float(x_eval),
        "resultado": float(resultado),
        "grado": n - 1,
        "tabla_diferencias": tabla.tolist(),
        "coeficientes_b": coeficientes,
        "pasos": pasos,
        "polinomio_newton_latex": sp.latex(poli_newton_expr),
        "polinomio_expandido_latex": sp.latex(poli_expandido_expr),
        "polinomio_geogebra": str(poli_expandido_expr).replace("**", "^"),
        "es_extrapolacion": es_extrapolacion,
        "rango_x": (x_min, x_max),
    }

def interpolacion_lineal(x_vals, y_vals, x_eval: float) -> dict:
    """
    Realiza interpolación lineal simple (si n = 2) o interpolación lineal
    segmentaria por tramos (si n > 2; Nieves & Domínguez, Sec. 5.1 y 5.7).
    Ordena los nodos por abscisa creciente, construye cada recta S_k(x) en [x_k, x_{k+1}],
    identifica el subintervalo activo y evalúa P_1(x_eval).
    """
    valido, msg, x, y = _validar_puntos_interpolacion(x_vals, y_vals, min_puntos=2)
    if not valido:
        return {"exito": False, "mensaje": msg}

    # Ordenar pares (x_i, y_i) de forma ascendente respecto a X
    orden = np.argsort(x)
    x = x[orden]
    y = y[orden]
    n = len(x)

    segmentos = []
    for k in range(n - 1):
        dx = x[k + 1] - x[k]
        if abs(dx) < 1e-15:
            return {
                "exito": False,
                "mensaje": f"División por cero en tramo {k}: x[{k+1}] - x[{k}] = 0.",
            }
        pendiente = (y[k + 1] - y[k]) / dx
        intercepto = y[k] - pendiente * x[k]
        segmentos.append(
            {
                "tramo": k + 1,
                "x0": float(x[k]),
                "x1": float(x[k + 1]),
                "y0": float(y[k]),
                "y1": float(y[k + 1]),
                "pendiente": float(pendiente),
                "intercepto": float(intercepto),
                "ecuacion_texto": f"S_{k+1}(x) = {y[k]:.6g} + ({pendiente:.6g})*(x - {x[k]:.6g})",
                "ecuacion_canonica": f"{pendiente:.8g}*x + ({intercepto:.8g})",
            }
        )

    # Localizar subintervalo activo [x_k, x_{k+1}]
    es_extrapolacion = False
    tipo_extr = ""
    if x_eval < x[0]:
        idx_activo = 0
        es_extrapolacion = True
        tipo_extr = "Extrapolación hacia la izquierda (x_eval < x_min)"
    elif x_eval > x[-1]:
        idx_activo = n - 2
        es_extrapolacion = True
        tipo_extr = "Extrapolación hacia la derecha (x_eval > x_max)"
    else:
        idx_activo = 0
        for k in range(n - 1):
            if x[k] <= x_eval <= x[k + 1]:
                idx_activo = k
                break

    seg = segmentos[idx_activo]
    resultado = seg["y0"] + seg["pendiente"] * (x_eval - seg["x0"])

    # Expresión condicional para GeoGebra
    if len(segmentos) == 1:
        geogebra_expr = seg["ecuacion_canonica"]
    else:
        # Construcción anidada Si(x <= x_1, S_1, Si(x <= x_2, S_2, ..., S_{n-1}))
        geogebra_expr = segmentos[-1]["ecuacion_canonica"]
        for k in range(len(segmentos) - 2, -1, -1):
            s_k = segmentos[k]
            geogebra_expr = f"If(x <= {s_k['x1']}, {s_k['ecuacion_canonica']}, {geogebra_expr})"

    return {
        "exito": True,
        "mensaje": "Interpolación lineal calculada exitosamente.",
        "metodo": "Interpolación Lineal (Pieza 5.5.D)",
        "x": x.tolist(),
        "y": y.tolist(),
        "x_eval": float(x_eval),
        "resultado": float(resultado),
        "tramo_activo": seg,
        "segmentos": segmentos,
        "es_extrapolacion": es_extrapolacion,
        "advertencia_extrapolacion": tipo_extr,
        "polinomio_geogebra": geogebra_expr,
    }

    # -------------------------------------------------------------------------
    # 3.1 ELIMINACIÓN GAUSSIANA CON PIVOTAJE PARCIAL
    # -------------------------------------------------------------------------
    @staticmethod
    def eliminacion_gaussiana(A, b):
        A = np.array(A, dtype=float)
        b = np.array(b, dtype=float).reshape(-1, 1)
        n = len(b)
        Ab = np.hstack([A, b])

        pasos_matriz = []
        pasos_matriz.append({
            "paso": "Matriz Aumentada Inicial [A|b]",
            "formula": "Estado inicial",
            "matriz": [[round(val, 4) for val in row] for row in Ab.tolist()],
        })

        paso_num = 1
        for k in range(n - 1):
            # Pivotaje Parcial
            max_row = np.argmax(np.abs(Ab[k:, k])) + k
            if Ab[max_row, k] == 0:
                raise ValueError("El sistema no tiene solución única (pivote nulo).")
            if max_row != k:
                Ab[[k, max_row]] = Ab[[max_row, k]]
                pasos_matriz.append({
                    "paso": f"Paso {paso_num}: Pivotaje Parcial",
                    "formula": f"Intercambio Fila L_{k+1} <-> Fila L_{max_row+1}",
                    "matriz": [[round(val, 4) for val in row] for row in Ab.tolist()],
                })
                paso_num += 1

            # Eliminación hacia adelante
            for i in range(k + 1, n):
                mult = Ab[i, k] / Ab[k, k]
                Ab[i, k:] -= mult * Ab[k, k:]
                pasos_matriz.append({
                    "paso": f"Paso {paso_num}: Eliminación de A[{i+1}][{k+1}]",
                    "formula": f"L_{i+1} = L_{i+1} - ({mult:.4f}) * L_{k+1}",
                    "matriz": [[round(val, 4) for val in row] for row in Ab.tolist()],
                })
                paso_num += 1

        # Sustitución hacia atrás
        x = np.zeros(n)
        for i in range(n - 1, -1, -1):
            if Ab[i, i] == 0:
                raise ZeroDivisionError("Cero en la diagonal durante la sustitución hacia atrás.")
            x[i] = (Ab[i, -1] - np.dot(Ab[i, i + 1 : n], x[i + 1 : n])) / Ab[i, i]

        return {
            "metodo": "Eliminación Gaussiana con Pivotaje Parcial",
            "matriz_triangular": [[round(val, 4) for val in row] for row in Ab[:, :-1].tolist()],
            "solucion": [round(val, 4) for val in x.tolist()],
            "pasos_matriz": pasos_matriz,
        }

    @staticmethod
    def gauss_jordan(A, b):
        A = np.array(A, dtype=float)
        b = np.array(b, dtype=float).reshape(-1, 1)
        n = len(b)
        Ab = np.hstack([A, b])

        pasos_matriz = []
        pasos_matriz.append({
            "paso": "Matriz Aumentada Inicial [A|b]",
            "formula": "Estado inicial",
            "matriz": [[round(val, 4) for val in row] for row in Ab.tolist()],
        })

        paso_num = 1
        for k in range(n):
            # Pivotaje Parcial
            max_row = np.argmax(np.abs(Ab[k:, k])) + k
            if Ab[max_row, k] == 0:

            if max_row != k:

            # Normalizar fila pivote
            pivote = Ab[k, k]
            Ab[k] = Ab[k] / pivote

                "matriz": [[round(val, 4) for val in row] for row in Ab.tolist()],

            for i in range(n):
                if i != k:
                    factor = Ab[i, k]
                    if abs(factor) > 1e-12:
                        Ab[i] -= factor * Ab[k]
                        pasos_matriz.append({

                            "matriz": [[round(val, 4) for val in row] for row in Ab.tolist()],
                        })
                        paso_num += 1

        return {
            "metodo": "Gauss-Jordan con Pivotaje Parcial",
            "solucion": [round(val, 4) for val in Ab[:, -1].tolist()],

        }

    # -------------------------------------------------------------------------
    # 3.3 MÉTODO ITERATIVO DE JACOBI
    # -------------------------------------------------------------------------
    @staticmethod
    def jacobi(A, b, x0=None, tol=1e-4, max_iter=30, tipo_error="residuo"):
        A = np.array(A, dtype=float)
        b = np.array(b, dtype=float)
        n = len(b)
        x = np.zeros(n) if x0 is None else np.array(x0, dtype=float)

        D = np.diag(A)
        if np.any(D == 0):
            raise ZeroDivisionError("Cero detectado en la diagonal principal de A.")

        R = A - np.diagflat(D)
        historial = []
        convergio = False

        for k in range(1, max_iter + 1):
            x_new = (b - np.dot(R, x)) / D

            if tipo_error == "residuo":
                residuos = np.abs(b - np.dot(A, x_new))
                err_eval = float(np.max(residuos))
            else:
                err_eval = float(np.linalg.norm(x_new - x))

            row_iter = {"i": k}
            for idx in range(n):
                row_iter[f"x_{idx+1}"] = round(x_new[idx], 5)
            row_iter["Error"] = round(err_eval, 5)
            historial.append(row_iter)

            if err_eval <= tol:
                convergio = True
                break
            x = x_new

        return {
            "metodo": "Jacobi",
            "solucion": [round(val, 5) for val in x.tolist()],
            "convergio": convergio,
            "iteraciones": historial,
        }

        A = np.array(A, dtype=float)

            if tipo_error == "residuo":
                residuos = np.abs(b - np.dot(A, x))
                err_eval = float(np.max(residuos))
            else:
                err_eval = float(np.linalg.norm(x - x_old))

                convergio = True
                break

            "metodo": "Gauss-Seidel",
            "solucion": [round(val, 5) for val in x.tolist()],
            "convergio": convergio,

import numpy as np
import sympy as sp


def _validar_datos_regresion(x_vals, y_vals, min_puntos: int = 2):
    """
    Valida dimensiones, ausencia de NaN/Inf y dispersión mínima en X
    para evitar sistemas normales singulares.
    """
    x = np.asarray(x_vals, dtype=float)
    y = np.asarray(y_vals, dtype=float)

    if x.ndim != 1 or y.ndim != 1 or len(x) != len(y):
        return False, "Los vectores X e Y deben ser unidimensionales y de igual longitud.", None, None

    if len(x) < min_puntos:
        return False, f"Se requieren al menos {min_puntos} pares de datos para este ajuste.", None, None

    if np.any(np.isnan(x)) or np.any(np.isnan(y)) or np.any(np.isinf(x)) or np.any(np.isinf(y)):
        return False, "Los datos contienen valores NaN o infinitos.", None, None

    if np.ptp(x) < 1e-15:
        return False, "Error de estabilidad: todos los valores de X son idénticos (varianza nula).", None, None

    return True, "OK", x, y


def _calcular_metricas_ajuste(y_real: np.ndarray, y_est: np.ndarray, num_parametros: int) -> dict:
    """
    Calcula St (suma total de cuadrados), Sr (suma de residuos al cuadrado),
    coeficiente de determinación R^2, correlación r y error estándar s_{y/x}
    en el espacio original de la variable dependiente Y.
    """
    n = len(y_real)
    y_prom = float(np.mean(y_real))
    st = float(np.sum((y_real - y_prom) ** 2))
    sr = float(np.sum((y_real - y_est) ** 2))

    if st < 1e-15:
        r2 = 1.0 if sr < 1e-15 else 0.0
    else:
        r2 = float(1.0 - (sr / st))

    r_pearson = float(np.sqrt(max(0.0, min(1.0, r2))))

    grados_libertad = n - num_parametros
    if grados_libertad > 0:
        error_estandar = float(np.sqrt(sr / grados_libertad))
    else:
        error_estandar = float("nan")

    return {
        "st": st,
        "sr": sr,
        "r2": r2,
        "r": r_pearson,
        "error_estandar": error_estandar,
        "grados_libertad": grados_libertad,
    }


def _verificar_extrapolacion(x: np.ndarray, x_eval: float) -> tuple[bool, tuple[float, float]]:
    x_min, x_max = float(np.min(x)), float(np.max(x))
    return bool(x_eval < x_min or x_eval > x_max), (x_min, x_max)


# =============================================================================
# PIEZA 6.1.A: REGRESIÓN LINEAL SIMPLE (MÍNIMOS CUADRADOS)
# =============================================================================
def regresion_lineal_simple(x_vals, y_vals, x_eval: float) -> dict:
    """
    Ajusta el modelo y = a_0 + a_1 * x mediante ecuaciones normales
    (Nieves & Domínguez, Sec. 6.1).
    """
    valido, msg, x, y = _validar_datos_regresion(x_vals, y_vals, min_puntos=2)
    if not valido:
        return {"exito": False, "mensaje": msg}

    n = len(x)
    sum_x = float(np.sum(x))
    sum_y = float(np.sum(y))
    sum_x2 = float(np.sum(x ** 2))
    sum_xy = float(np.sum(x * y))
    sum_y2 = float(np.sum(y ** 2))

    denom = n * sum_x2 - sum_x ** 2
    if abs(denom) < 1e-15:
        return {"exito": False, "mensaje": "Sistema normal singular (determinante nulo)."}

    a1 = (n * sum_xy - sum_x * sum_y) / denom
    a0 = (sum_y - a1 * sum_x) / n

    y_est = a0 + a1 * x
    metricas = _calcular_metricas_ajuste(y, y_est, num_parametros=2)
    if a1 < 0:
        metricas["r"] = -metricas["r"]

    y_proj = float(a0 + a1 * x_eval)
    es_extrap, rango_x = _verificar_extrapolacion(x, x_eval)

    signo = "+" if a1 >= 0 else "-"
    latex_ec = f"y = {a0:.6g} {signo} {abs(a1):.6g}x"
    ggb_ec = f"{a0:.10g} + ({a1:.10g})*x"

    return {
        "exito": True,
        "mensaje": "Regresión lineal calculada correctamente.",
        "metodo": "Regresión Lineal Simple (Pieza 6.1.A)",
        "x": x.tolist(),
        "y": y.tolist(),
        "y_estimado": y_est.tolist(),
        "x_eval": float(x_eval),
        "resultado": y_proj,
        "parametros": {"a0": float(a0), "a1": float(a1)},
        "sumatorias": {
            "n": n,
            "sum_x": sum_x,
            "sum_y": sum_y,
            "sum_x2": sum_x2,
            "sum_xy": sum_xy,
            "sum_y2": sum_y2,
        },
        "matriz_normal": [[float(n), sum_x], [sum_x, sum_x2]],
        "vector_normal": [sum_y, sum_xy],
        "metricas": metricas,
        "ecuacion_latex": latex_ec,
        "funcion_geogebra": ggb_ec,
        "es_extrapolacion": es_extrap,
        "rango_x": rango_x,
    }


# =============================================================================
# PIEZA 6.2.B: REGRESIÓN POLINOMIAL DE GRADO m
# =============================================================================
def regresion_polinomial(x_vals, y_vals, grado: int, x_eval: float) -> dict:
    """
    Ajusta un polinomio P_m(x) = a_0 + a_1*x + ... + a_m*x^m por mínimos cuadrados
    resolviendo el sistema normal [A]{a} = {B} (Nieves & Domínguez, Sec. 6.2).
    """
    if grado < 1:
        return {"exito": False, "mensaje": "El grado del polinomio debe ser mayor o igual a 1."}

    valido, msg, x, y = _validar_datos_regresion(x_vals, y_vals, min_puntos=grado + 1)
    if not valido:
        return {"exito": False, "mensaje": msg}

    n = len(x)
    m = int(grado)
    dim = m + 1

    # Construcción de la matriz normal simétrica A (dim x dim) y vector B
    A = np.zeros((dim, dim), dtype=float)
    B = np.zeros(dim, dtype=float)

    potencias_x = {k: float(np.sum(x ** k)) for k in range(2 * m + 1)}
    for j in range(dim):
        for k in range(dim):
            A[j, k] = potencias_x[j + k]
        B[j] = float(np.sum((x ** j) * y))

    cond = float(np.linalg.cond(A))
    if cond > 1e14:
        return {
            "exito": False,
            "mensaje": f"Matriz normal mal condicionada o singular (cond = {cond:.2e}). Reduzca el grado.",
        }

    coeficientes = np.linalg.solve(A, B)

    # Evaluación mediante esquema de Horner (Sec. 2.10)
    def evaluar_horner(val):
        acc = coeficientes[-1]
        for c in range(m - 1, -1, -1):
            acc = acc * val + coeficientes[c]
        return acc

    y_est = np.array([evaluar_horner(xi) for xi in x], dtype=float)
    y_proj = float(evaluar_horner(x_eval))
    metricas = _calcular_metricas_ajuste(y, y_est, num_parametros=dim)
    es_extrap, rango_x = _verificar_extrapolacion(x, x_eval)

    # Construcción simbólica con SymPy
    x_sym = sp.Symbol("x")
    expr = sum(sp.Float(coeficientes[k], 8) * (x_sym ** k) for k in range(dim))
    latex_ec = f"y = {sp.latex(expr)}"
    ggb_ec = " + ".join(f"({coeficientes[k]:.10g})*x^{k}" for k in range(dim))

    advertencia = ""
    if m == n - 1:
        advertencia = "Grado m = n - 1: el ajuste degenera en interpolación exacta (0 grados de libertad)."
    elif cond > 1e9:
        advertencia = f"Advertencia de condicionamiento elevado en matriz normal (cond = {cond:.2e})."

    return {
        "exito": True,
        "mensaje": "Regresión polinomial calculada correctamente.",
        "metodo": f"Regresión Polinomial de Grado {m} (Pieza 6.2.B)",
        "grado": m,
        "x": x.tolist(),
        "y": y.tolist(),
        "y_estimado": y_est.tolist(),
        "x_eval": float(x_eval),
        "resultado": y_proj,
        "coeficientes": [float(c) for c in coeficientes],
        "matriz_normal": A.tolist(),
        "vector_normal": B.tolist(),
        "numero_condicion": cond,
        "metricas": metricas,
        "ecuacion_latex": latex_ec,
        "funcion_geogebra": ggb_ec,
        "es_extrapolacion": es_extrap,
        "rango_x": rango_x,
        "advertencia": advertencia,
    }

def regresion_exponencial(x_vals, y_vals, x_eval: float) -> dict:
    """
    Ajusta el modelo no lineal y = a * exp(b * x) mediante transformación
    logarítmica ln(y) = ln(a) + b*x (Nieves & Domínguez, Sec. 6.3).
    """
    valido, msg, x, y = _validar_datos_regresion(x_vals, y_vals, min_puntos=2)
    if not valido:
        return {"exito": False, "mensaje": msg}

    if np.any(y <= 0):
        return {
            "exito": False,
            "mensaje": "Error de dominio: el modelo exponencial y = a·e^(bx) requiere que todos los valores de Y sean estrictamente positivos (y_i > 0).",
        }

    z = np.log(y)
    lin = regresion_lineal_simple(x, z, x_eval)
    if not lin["exito"]:
        return {"exito": False, "mensaje": lin["mensaje"]}

    a0 = lin["parametros"]["a0"]
    b = lin["parametros"]["a1"]
    a = float(np.exp(a0))

    y_est = a * np.exp(b * x)
    y_proj = float(a * np.exp(b * x_eval))
    metricas = _calcular_metricas_ajuste(y, y_est, num_parametros=2)
    metricas["r2_linealizado"] = lin["metricas"]["r2"]
    es_extrap, rango_x = _verificar_extrapolacion(x, x_eval)

    latex_ec = f"y = {a:.6g} e^{{{b:.6g}x}}"
    ggb_ec = f"({a:.10g}) * exp(({b:.10g}) * x)"

    return {

        "metodo": "Regresión Exponencial (Pieza 6.3.C)",

        "y_estimado": y_est.tolist(),

def comparar_modelos_proyeccion(x_vals, y_vals, x_eval: float, grado_poli: int = 2) -> dict:
    """
    Ejecuta todos los modelos aplicables (6.1.A a 6.5.E), ordena los válidos por
    coeficiente de determinación R^2 descendente y selecciona el mejor modelo de proyección.
    """
    candidatos = [
        ("6.1.A Lineal", regresion_lineal_simple(x_vals, y_vals, x_eval)),
        (f"6.2.B Polinomial (g={grado_poli})", regresion_polinomial(x_vals, y_vals, grado_poli, x_eval)),
        ("6.3.C Exponencial", regresion_exponencial(x_vals, y_vals, x_eval)),
        ("6.4.D Potencial", regresion_potencial(x_vals, y_vals, x_eval)),
        ("6.5.E Logarítmico", regresion_logaritmica(x_vals, y_vals, x_eval)),
    ]

    validos = []
    descartados = []

    for nombre, res in candidatos:
        if res.get("exito"):
            validos.append(
                {
                    "modelo": nombre,
                    "ecuacion_latex": res["ecuacion_latex"],
                    "funcion_geogebra": res["funcion_geogebra"],
                    "proyeccion": res["resultado"],
                    "r2": res["metricas"]["r2"],
                    "error_estandar": res["metricas"]["error_estandar"],
                    "sr": res["metricas"]["sr"],
                    "detalle": res,
                }
            )
        else:
            descartados.append({"modelo": nombre, "motivo": res.get("mensaje", "No aplicable")})

    if not validos:
        return {
            "exito": False,
            "mensaje": "Ningún modelo pudo ajustarse a los datos proporcionados.",
            "descartados": descartados,
        }

    # Ordenar por R^2 descendente (y menor Sr en caso de empate)
    validos.sort(key=lambda item: (-item["r2"], item["sr"]))

    return {
        "exito": True,
        "mensaje": "Comparativa de modelos completada.",
        "mejor_modelo": validos[0],
        "ranking": validos,
        "descartados": descartados,
    }

# PIEZA 6.6.F: ANÁLISIS Y PRONÓSTICO DE SERIES DE TIEMPO
# =============================================================================
def _metricas_series_tiempo(y_real: np.ndarray, y_pron: np.ndarray) -> dict:
    """
    Calcula métricas estándar de error en series de tiempo sobre los periodos
    donde existe pronóstico válido (no NaN): MAD, MSE, RMSE y MAPE (%).
    """
    mask = ~np.isnan(y_pron)
    yr = y_real[mask]
    yp = y_pron[mask]

    if len(yr) == 0:
        return {"mad": float("nan"), "mse": float("nan"), "rmse": float("nan"), "mape": float("nan")}

    errores = yr - yp
    abs_err = np.abs(errores)
    mad = float(np.mean(abs_err))
    mse = float(np.mean(errores ** 2))
    rmse = float(np.sqrt(mse))

    # MAPE evitando división por cero si algún y_t == 0
    mask_no_cero = np.abs(yr) > 1e-12
    if np.any(mask_no_cero):
        mape = float(np.mean(abs_err[mask_no_cero] / np.abs(yr[mask_no_cero])) * 100.0)
    else:
        mape = float("nan")

    return {"mad": mad, "mse": mse, "rmse": rmse, "mape": mape}


def pronostico_series_tiempo(
    y_vals,
    submetodo: str = "SES",
    ventana_k: int = 3,
    pesos: list | None = None,
    alpha: float = 0.3,
    beta: float = 0.1,
    horizonte_h: int = 1,
    periodo_estacional: int = 4,
    t_vals=None,
) -> dict:
    """
    Ejecuta pronósticos de series de tiempo univariadas y_1, y_2, ..., y_n:
      - 'PMS': Promedio Móvil Simple de orden k
      - 'PMP': Promedio Móvil Ponderado de orden k (pesos suman 1)
      - 'SES': Suavizamiento Exponencial Simple (alpha)
      - 'HOLT': Suavizamiento Exponencial Doble de Holt (alpha, beta)
      - 'ESTACIONAL': Descomposición Multiplicativa (Tendencia Lineal + Índices Estacionales)
    """
    y = np.asarray(y_vals, dtype=float)
    if y.ndim != 1 or len(y) < 3:
        return {"exito": False, "mensaje": "La serie de tiempo requiere al menos 3 observaciones."}
    if np.any(np.isnan(y)) or np.any(np.isinf(y)):
        return {"exito": False, "mensaje": "La serie contiene valores NaN o infinitos."}

    n = len(y)
    t = np.arange(1, n + 1, dtype=float) if t_vals is None else np.asarray(t_vals, dtype=float)
    dt = float(t[1] - t[0]) if len(t) > 1 else 1.0
    t_futuro = np.array([t[-1] + (h * dt) for h in range(1, horizonte_h + 1)], dtype=float)

    y_ajuste = np.full(n, np.nan, dtype=float)
    pronosticos_futuros = np.zeros(horizonte_h, dtype=float)
    detalles_extra = {}

    # 1. PROMEDIO MÓVIL SIMPLE (PMS)
    if submetodo == "PMS":
        k = int(ventana_k)
        if k < 1 or k >= n:
            return {"exito": False, "mensaje": f"La ventana k debe cumplir 1 <= k < {n}."}
        for i in range(k, n):
            y_ajuste[i] = np.mean(y[i - k : i])
        # Pronóstico futuro iterativo (o nivel constante del último bloque)
        serie_ext = list(y)
        for h in range(horizonte_h):
            val_next = float(np.mean(serie_ext[-k:]))
            pronosticos_futuros[h] = val_next
            serie_ext.append(val_next)
        nombre_metodo = f"Promedio Móvil Simple (k = {k})"

    # 2. PROMEDIO MÓVIL PONDERADO (PMP)
    elif submetodo == "PMP":
        if not pesos or len(pesos) < 2:
            return {"exito": False, "mensaje": "Debe proporcionar al menos 2 pesos para el PMP."}
        w = np.asarray(pesos, dtype=float)
        if np.any(w < 0) or np.sum(w) <= 0:
            return {"exito": False, "mensaje": "Los pesos deben ser no negativos y sumar > 0."}
        w = w / np.sum(w)  # Normalización automática a suma = 1
        k = len(w)
        if k >= n:
            return {"exito": False, "mensaje": f"El número de pesos ({k}) debe ser menor que n ({n})."}
        for i in range(k, n):
            y_ajuste[i] = float(np.dot(y[i - k : i], w))
        serie_ext = list(y)
        for h in range(horizonte_h):
            val_next = float(np.dot(serie_ext[-k:], w))
            pronosticos_futuros[h] = val_next
            serie_ext.append(val_next)
        detalles_extra["pesos_normalizados"] = w.tolist()
        nombre_metodo = f"Promedio Móvil Ponderado (k = {k})"

    # 3. SUAVIZAMIENTO EXPONENCIAL SIMPLE (SES)
    elif submetodo == "SES":
        if not (0.0 < alpha <= 1.0):
            return {"exito": False, "mensaje": "El parámetro alpha debe estar en (0, 1]."}
        y_ajuste[0] = y[0]
        for i in range(1, n):
            y_ajuste[i] = alpha * y[i - 1] + (1.0 - alpha) * y_ajuste[i - 1]
        ultimo_pron = float(alpha * y[-1] + (1.0 - alpha) * y_ajuste[-1])
        pronosticos_futuros[:] = ultimo_pron
        nombre_metodo = f"Suavizamiento Exponencial Simple (α = {alpha:.3f})"

    # 4. SUAVIZAMIENTO EXPONENCIAL DOBLE DE HOLT (NIVEL + TENDENCIA)
    elif submetodo == "HOLT":
        if not (0.0 < alpha <= 1.0) or not (0.0 <= beta <= 1.0):
            return {"exito": False, "mensaje": "Los parámetros alpha y beta deben estar en (0, 1]."}
        L = np.zeros(n, dtype=float)
        T = np.zeros(n, dtype=float)
        L[0] = y[0]
        T[0] = y[1] - y[0]
        y_ajuste[0] = y[0]
        for i in range(1, n):
            y_ajuste[i] = L[i - 1] + T[i - 1]
            L[i] = alpha * y[i] + (1.0 - alpha) * (L[i - 1] + T[i - 1])
            T[i] = beta * (L[i] - L[i - 1]) + (1.0 - beta) * T[i - 1]
        for h in range(1, horizonte_h + 1):
            pronosticos_futuros[h - 1] = L[-1] + h * T[-1]
        detalles_extra["nivel_final"] = float(L[-1])
        detalles_extra["tendencia_final"] = float(T[-1])
        nombre_metodo = f"Suavizamiento Doble de Holt (α = {alpha:.2f}, β = {beta:.2f})"

    # 5. DESCOMPOSICIÓN ESTACIONAL MULTIPLICATIVA (TENDENCIA + ÍNDICES ESTACIONALES)
    elif submetodo == "ESTACIONAL":
        L_per = int(periodo_estacional)
        if L_per < 2 or n < 2 * L_per:
            return {
                "exito": False,
                "mensaje": f"Se requieren al menos 2 ciclos completos (n >= {2 * L_per}) para periodo L = {L_per}.",
            }
        if np.any(y <= 0):
            return {
                "exito": False,
                "mensaje": "La descomposición multiplicativa requiere valores positivos (y_t > 0).",
            }
        # Tendencia lineal base sobre índice temporal 1..n
        idx_t = np.arange(1, n + 1, dtype=float)
        tend_lin = regresion_lineal_simple(idx_t, y, float(n + 1))
        a0 = tend_lin["parametros"]["a0"]
        a1 = tend_lin["parametros"]["a1"]
        tendencia_hist = a0 + a1 * idx_t

        # Razón y_t / Tendencia_t agrupada por estación (0 .. L_per - 1)
        razones = y / tendencia_hist
        indices_brutos = np.zeros(L_per, dtype=float)
        for s in range(L_per):
            indices_brutos[s] = float(np.mean(razones[s::L_per]))
        # Normalizar para que los índices sumen exactamente L_per
        indices_est = indices_brutos * (L_per / np.sum(indices_brutos))

        for i in range(n):
            y_ajuste[i] = tendencia_hist[i] * indices_est[i % L_per]

        for h in range(1, horizonte_h + 1):
            t_idx_fut = n + h
            est_idx = (t_idx_fut - 1) % L_per
            pronosticos_futuros[h - 1] = (a0 + a1 * t_idx_fut) * indices_est[est_idx]

        detalles_extra["indices_estacionales"] = [round(float(val), 4) for val in indices_est]
        detalles_extra["tendencia_base"] = f"T(t) = {a0:.4f} + {a1:.4f}·t"
        nombre_metodo = f"Descomposición Estacional Multiplicativa (L = {L_per})"

    else:
        return {"exito": False, "mensaje": f"Submétodo de serie de tiempo no reconocido: {submetodo}"}

    metricas = _metricas_series_tiempo(y, y_ajuste)

    # Polinomio segmentario para visualizar la curva suavizada/pronosticada en GeoGebra
    t_comb = np.concatenate([t, t_futuro])
    y_comb = np.concatenate([np.where(np.isnan(y_ajuste), y, y_ajuste), pronosticos_futuros])
    tramos_ggb = []
    for k in range(len(t_comb) - 1):
        m_k = (y_comb[k + 1] - y_comb[k]) / (t_comb[k + 1] - t_comb[k])
        b_k = y_comb[k] - m_k * t_comb[k]
        tramos_ggb.append((t_comb[k + 1], f"({m_k:.8g}*x + ({b_k:.8g}))"))

    ggb_expr = tramos_ggb[-1][1]
    for k in range(len(tramos_ggb) - 2, -1, -1):
        ggb_expr = f"If(x <= {tramos_ggb[k][0]}, {tramos_ggb[k][1]}, {ggb_expr})"

    return {
        "exito": True,
        "mensaje": "Pronóstico de serie de tiempo calculado correctamente.",
        "metodo": f"Series de Tiempo — {nombre_metodo} (Pieza 6.6.F)",
        "t": t.tolist(),
        "y": y.tolist(),
        "y_ajuste": y_ajuste.tolist(),
        "t_futuro": t_futuro.tolist(),
        "pronosticos_futuros": pronosticos_futuros.tolist(),
        "resultado": float(pronosticos_futuros[0]),
        "x_eval": float(t_futuro[0]),
        "metricas": metricas,
        "detalles_extra": detalles_extra,
        "funcion_geogebra": ggb_expr,
    }

                "enableRightClick": true,
                "language": "es",
                "appletOnLoad": function(api) {{
                    var cmds = {comandos_json};
                    cmds.forEach(function(cmd) {{

                    }});
